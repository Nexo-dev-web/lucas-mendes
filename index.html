Conectar à plataforma

Use o mesmo e-mail e senha que você usa para entrar no app/site da RRJ. As credenciais ficam só na memória do navegador — nada é salvo ou enviado para outro lugar além do próprio servidor da RRJ.

Nota técnica: essa página chama a API REST do Traccar (/api/devices e /api/positions) direto do seu navegador, usando autenticação HTTP Basic. Se o servidor bloquear requisições de outra origem (CORS), a conexão vai falhar mesmo com credenciais corretas — nesse caso a integração final precisa passar pelo backend do seu sistema em vez do navegador.
